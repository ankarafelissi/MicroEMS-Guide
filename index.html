02 / CONFIGURATION

Define the operating limits

Left panel · Configuration

Set the operating requirements, then check equipment capabilities. Soft targets may be exceeded; hard limits and SOC bounds must be respected.

Operating requirements
ParameterDefaultWhat it means
Reserve SOC30%The battery's minimum state of charge. Operation must stay at or above this level.
Grid import soft target1.5 kWEnabled by defaultThe optimizer first tries to minimize energy imported above this target. Exceedances are allowed and counted.
Grid import hard limitDisabledInitial input: 3 kWWhen enabled, this limit must be satisfied. The effective limit is the lower of this setting and the equipment import capacity.
Optimization objectiveCost firstReduce net electricity cost after addressing the soft target. Peak first minimizes the import peak before optimizing cost.
Battery & equipmentExpand defaults+
Battery capacity5.0 kWh
Charge / discharge limit2.0 kW
Initial SOC50 %
Minimum final SOC50 %
Maximum SOC90 %
Grid import capacity5.0 kW
Grid export capacity3.0 kW

Initial and minimum final SOC must both fall between reserve SOC and maximum SOC.

SOFT TARGET

Meet it where possible

A low target may be exceeded. The results count the intervals above it.

HARD CONSTRAINT

Always respect it

If the requirements cannot all be met, the system reports a conflict instead of relaxing the constraints.

03 / EXECUTION

Control the pace

STEP

One interval at a time

Execute next 15 minutes

Read current data, update the remaining plan and execute only the next interval. Use this mode to examine each step.

AUTO

Run continuously

Auto run / resume

Advance automatically at 0.2, 1 or 3 seconds per step. Each step still represents 15 minutes.

PAUSE

Pause and inspect

Pause

Pause after the currently calculating step finishes. Completed records are kept, and execution can be resumed.

!

Closing the page does not pause an automatic run. Click Pause first if you want to stop advancing. The step interval controls simulation playback speed, not a real-time control cycle.

04 / MONITORING

Read the trends, then the results

Dashboard · Results tabs

Three curves, three roles

The day-ahead plan is the fixed reference. The latest revision shows the updated plan. Actual data covers completed intervals.

  • Day-ahead plan / forecastGenerated before execution and kept unchanged.
  • Latest plan / forecastUpdated from the observations available so far.
  • Actual execution / dataAdded step by step. Future actual values are not shown.
Comparing the curvesIllustration only
