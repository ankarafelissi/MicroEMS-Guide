03 / EXECUTION

掌握执行节奏

STEP

单步执行

执行下一个15分钟

读取当前时段数据，调整后续计划，只执行当前一步。适合逐点观察。

AUTO

连续推进

自动运行 / 继续

按选定间隔自动执行。可选 0.2、1 或 3 秒 / 步；每步始终代表 15 分钟。

PAUSE

暂停检查

暂停

当前正在计算的一步结束后暂停。已完成的执行记录保留，可继续运行。

!

关闭网页不会暂停自动运行。离开前如需停止推进，请先点击「暂停」。推进间隔是仿真播放速度，不是现实中的控制周期。

根据状态判断下一步

日前计划已就绪

可以单步执行或开始自动运行。

自动运行中

系统连续推进；需要检查时点击暂停。

已暂停

可以继续自动运行，也可以改用单步执行。

全天执行完成

96 个时段已结束，可以查看和导出结果。

要求冲突 / 执行已停止

查看提示的冲突原因，调整参数后生成新方案。

04 / MONITORING

先看趋势，再看结果

主界面 · 结果标签页

三条曲线，三种含义

日前计划作为固定参照，最新调整反映重算结果，实际执行记录已经完成的时段。

  • 日前计划 / 日前预测开始前生成，后续保持不变。
  • 最新调整 / 最新预测根据已观测数据更新的剩余计划。
  • 实际执行 / 实际数据随执行逐点增加，尚未执行的未来不会显示实际值。
曲线对照示意非实时数据
01

储能功率

正值表示放电，负值表示充电。结合电价判断充放电安排。

02

电池荷电状态

显示各时段末 SOC；虚线标出备用 SOC 下限。

03

光伏出力

对比日前预测、最新预测与已执行时段的实际光伏。

04

电网购电

观察购电峰值与软目标线，定位超过目标的时段。

05

用电负荷

对比预测与实际负荷，观察日内修正后的变化。

06

分时电价

查看全天购电、售电价格，理解调度的时间安排。

关键指标速查
查看位置指标含义
运行总览当前 SOC / 累计净电费当前剩余电量比例；已执行时段的购电费用减售电收入。
运行总览实际购电峰值 / 软目标超限时段已执行时段的最大购电功率，以及超过购电软目标的时段数。
预测评测MAE / RMSE仅对已执行时段计算，越小代表误差越低；RMSE 对较大误差更敏感。
运行效果约束检查 / 参考电费 / 相对参考节省检查已执行时段；参考为同期无储能费用，中途节省未校正电池剩余电量。

06 / TROUBLESHOOTING

遇到问题，先看这里

为什么提示「运行要求冲突」？+

先按错误提示检查：购电硬上限是否过低、备用 SOC 是否过高，以及初始 / 日末 SOC 是否处在允许范围。要求无法同时满足时，请调整参数后生成新方案；已有方案不会被自动放宽约束。

为什么 MAE 和 RMSE 显示「—」？+

尚无实际执行数据时无法计算误差。执行一个时段后，系统开始累计预测评测；只查看计划不会产生实际样本。

修改了左侧参数，当前计划为什么没变化？+

表单参数仅在点击「生成日前计划」时提交，并创建新方案。当前打开的历史方案继续使用其原来的参数。

刷新页面会重复执行吗？关闭网页会停止吗？+

刷新只读取已保存的状态，不会重复推进。自动运行由后端继续执行，关闭网页不会暂停；需要停止时，请先点击「暂停」。

为什么执行按钮是灰色的？+

自动运行中，单步与开始按钮不可用；完成全天调度或遇到冲突后，也不能继续推进。暂停按钮仅在自动运行中可用。若要开始新一轮，请生成新的日前计划。

为什么无法打开调度中心？+

先确认调度中心服务在线。当前公网入口依赖运行服务的电脑和网络；如果临时公网地址已变化，请从最新的调度中心页面点击「操作指南」，指南会使用本次访问的地址提供返回入口。
